МЕТОДИЧКА ДО ЛАБОРАТОРНОЇ РОБОТИ № 3 
ПРОЕКТУВАННЯ ТА РЕАЛІЗАЦІЯ FRONT-END ЧЕРЕЗ FIGMA 
Мета роботи: навчитися основам проектування та реалізації сучасного інтерфейсу 
користувача (UI) з використанням Figma. Здобути навички створення якісного дизайну веб
сторінки, експорту макета у HTML, CSS та JavaScript для подальшої інтеграції у веб-додаток. 
Послідовність виконання завдання. 
1. Ознайомлення з вимогами 
o Вивчення сучасних принципів UI/UX-дизайну. 
o Ознайомлення з вимогами до розробки веб-інтерфейсів. 
2. Вибір теми 
o Кожен студент обирає одну з 20 запропонованих тем для розробки веб-дизайну 
(без повторення теми в межах групи). 
3. Проектування UI у Figma 
o Створення wireframe-структури сайту. 
o Використання сіток (grids), автошарів (auto-layout) та компонентів. 
o Опрацювання колірної схеми, типографіки, кнопок, форм, зображень та іконок. 
4. Прототипування 
o Налаштування інтерактивності елементів. 
o Тестування навігації та функціональності прототипу. 
5. Експорт дизайну у HTML, CSS, JavaScript 
o Використання можливостей експорту у Figma. 
o Генерація коду та його адаптація у редакторі коду.   
Експортувати спроектований дизайн у готовий HTML, CSS та навіть JavaScript. 
Доопрацювати дизайн відповідно до вимог. 
o Додавання базової взаємодії за допомогою JavaScript (наприклад, обробка 
подій). 
6. Адаптація дизайну під мобільні пристрої 
o Використання медіазапитів CSS. 
o Тестування на різних розмірах екранів. 
7. Презентація роботи 
o Захист проекту перед викладачем. 
o Обговорення ключових рішень у дизайні. 
ОЧІКУВАНИЙ РЕЗУЛЬТАТ: готовий макет веб-сайту у Figma з врахуванням всіх сучасних 
правил та вимог до розроблення front-end, експортований у HTML/CSS/JavaScript з адаптацією 
під мобільні пристрої та базовою інтерактивністю.  
Можливі підходи експорту макету. 
1. Figma-to-HTML Plugins: існують плагіни для Figma, які дозволяють експортувати 
дизайн у HTML, CSS та навіть JavaScript. Наприклад: 
o Figma to HTML – дозволяє експортувати елементи дизайну в код. 
o Anima – інший плагін, який дозволяє генерувати адаптивний HTML, CSS і 
JavaScript з вашого дизайну в Figma. 
2. Кодогенерація: Figma дає можливість експортувати CSS властивості для окремих 
елементів дизайну, таких як шрифти, кольори, розміри, відступи тощо. Однак цей 
експорт не включає повний функціональний код. Вам все одно доведеться вручну 
написати структуру HTML і JavaScript для інтерактивності. 
3. Інтеграція з інструментами розробки: існують інструменти, як Framer або Webflow, 
які можуть синхронізувати ваші дизайни з Figma та створювати інтерактивні веб
сторінки, де ви можете редагувати та експортувати код для подальшого використання. 
Вони також можуть генерувати деякі частини JavaScript для анімацій та інших ефектів. 
Обмеження, які потрібно врахувати: 
 точність – хоча плагіни й інструменти дають хороший старт, кінцевий результат часто 
потребує доопрацювання вручну, особливо якщо мова йде про інтерактивність та 
складну логіку; 
 оптимізація: код, згенерований автоматично, може бути не дуже оптимізованим, тому 
він потребуватиме подальшого поліпшення з точки зору структури та продуктивності. 
Вимоги до сучасного дизайну сайту. 
1. Адаптивність. Дизайн має коректно відображатися на різних розмірах екранів 
(мобільний, планшетний, десктоп). 
2. Чистота та простота. Мінімалізм у використанні кольорів та елементів дизайну, 
зрозуміле й зручне розташування. 
3. Швидкість завантаження. Використання оптимізованих зображень, мінімізація 
запитів до сервера для підвищення швидкості. 
4. Зручність користувача (UX/UI). Інтуїтивно зрозуміле меню навігації, чітка ієрархія 
інформації, логічне розташування кнопок та елементів. 
5. Інтерактивність. Використання анімацій, плавних переходів та ефектів при наведенні 
на елементи. 
6. Читабельність. Правильний вибір шрифтів, контрастність тексту з фоном, 
оптимальний розмір шрифтів для зручності читання. 
7. Використання сучасних стандартів. Використання сучасних технологій HTML5, 
CSS3, JavaScript, а також адаптивних фреймворків, таких як Bootstrap чи Tailwind CSS. 
8. Доступність. Забезпечення доступу до сайту для всіх користувачів, включаючи людей 
з інвалідністю (контрастні кольори, описові alt-тексти для зображень). 
9. Безпека. Інтеграція з HTTPS, використання сучасних методів аутентифікації та захисту 
даних. 
10. SEO-оптимізація. Використання правильних мета-тегів, семантичних тегів для 
покращення видимості сайту в пошукових системах. 
ВАРІАНТИ ЗАВДАНЬ 
1. Особистий блог – дизайн сторінки блогу з адаптивним макетом, елементами карток та 
меню навігації. 
2. Ресторанний сайт – створення веб-сайту для ресторану з меню, контактною 
інформацією та відгуками користувачів. 
3. Портфоліо дизайнера – лендінг для дизайнерського портфоліо з інтерактивними 
елементами, як галерея та анімація. 
4. Інтернет-магазин – розробка сторінки для інтернет-магазину з товарами, фільтрами 
пошуку та кошиком покупок. 
5. Лендінг пейдж для стартапу – опис продукту або послуги з фокусом на залучення 
клієнтів, CTA кнопки та анімаціями. 
6. Новини та статті – веб-сайт для публікації новин з різними категоріями та 
інтерактивним фільтром. 
7. Сайт для спортивної команди – створення дизайну для команди з розкладом, 
результатами матчів та профілями гравців. 
8. Агрегатор подій – розробка веб-сайту для пошуку та перегляду подій в місті з 
фільтрацією за категоріями. 
9. Музичний сайт – створення сторінки для музичного артиста або групи з інтеграцією 
відео та аудіо. 
10. Веб-сайт для благодійної організації – дизайн сайту для збору коштів, новини, відгуки 
та статистика. 
11. Система управління завданнями – сайт для персонального планувальника завдань з 
можливістю додавання завдань, фільтрації та відмітки виконання. 
12. Медичний портал – сайт для клініки з інформацією про лікарів, запис на прийом та 
відгуками пацієнтів. 
13. Сайт для школи або університету – розробка дизайну для навчального закладу з 
новинами, програмами та контактною інформацією. 
14. Сайт відгуків та рейтингів – платформа для залишення відгуків про товари чи 
послуги з можливістю фільтрації. 
15. Погода – сайт, що відображає прогноз погоди з інтерактивними картами та 
інформацією про температуру. 
16. Кулінарний сайт – розробка дизайну для сайту з рецептами, фотографіями страв та 
можливістю пошуку за інгредієнтами. 
17. Календар подій – веб-сайт з інтерактивним календарем, в якому можна переглядати та 
додавати події. 
18. Форум або чат – створення онлайн платформи для обміну повідомленнями між 
користувачами. 
19. Інтерфейс для онлайн-курсу – сайт для онлайн-курсу з відображенням уроків, 
прогресу та тестів. 
20. Сайт для пошуку роботи – платформа для пошуку вакансій з можливістю фільтрації 
та подачі заявки.
