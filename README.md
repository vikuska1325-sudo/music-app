# Luna Sky - Музичний Сайт

**Лабораторна робота №3**: Проектування та реалізація Front-End через Figma

**Варіант 9**: Музичний сайт – створення сторінки для музичного артиста або групи з інтеграцією відео та аудіо.

## Опис проєкту

Luna Sky - це сучасний односторінковий веб-сайт для музичної виконавиці, який демонструє її творчість, музику та відео. Сайт розроблений з використанням найсучасніших технологій та відповідає всім вимогам сучасного веб-дизайну.

## Ключові функції

### Основні можливості:
- 🎵 **Аудіо-плеєр** з повним функціоналом (відтворення, пауза, перемотка, регулювання гучності)
- 🎬 **Відео-галерея** з можливістю перегляду відео в модальному вікні
- 📱 **Повністю адаптивний дизайн** для всіх типів пристроїв
- 🎨 **Сучасний UI/UX** з градієнтами та анімаціями
- 📋 **Список треків** з можливістю фільтрації за альбомами
- 👤 **Розділ "Про артиста"** з біографією та досягненнями

### Додаткове завдання (+3 бали):
- 🎼 **Візуалізація музики** - реалізовано еквалайзер-анімацію, яка реагує на аудіо в реальному часі

## Технології

### Frontend Stack:
- **React 18.3.1** - JavaScript бібліотека для побудови інтерфейсів
- **TypeScript** - типізована надбудова над JavaScript
- **Tailwind CSS v4** - utility-first CSS фреймворк
- **Vite** - швидкий інструмент збірки

### UI Компоненти:
- **Radix UI** - доступні та настроювані UI компоненти
- **Lucide React** - бібліотека іконок
- **Motion (Framer Motion)** - бібліотека для анімацій

### Аудіо Візуалізація:
- **Web Audio API** - для аналізу аудіо в реальному часі
- **Canvas API** - для малювання еквалайзера

## Реалізація еквалайзера (додаткове завдання)

Еквалайзер використовує **Web Audio API** для аналізу аудіо в реальному часі:

1. **AudioContext** створює контекст для обробки аудіо
2. **AnalyserNode** аналізує частотні дані
3. **Canvas API** малює візуалізацію у вигляді барів
4. **RequestAnimationFrame** забезпечує плавну анімацію

Візуалізація реагує на музику в реальному часі, змінюючи висоту барів відповідно до рівня звуку на різних частотах.

```bash
# Побудова для production
pnpm run build
```
