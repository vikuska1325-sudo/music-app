## 6. ОСОБЛИВОСТІ РЕАЛІЗАЦІЇ

### 6.1 Еквалайзер (додаткове завдання)

**Алгоритм роботи**:
1. Створення аудіо контексту при монтуванні компонента
2. Підключення джерела аудіо до аналізатора
3. Отримання частотних даних (256 частот)
4. Візуалізація через Canvas API
5. Оновлення кадрів через requestAnimationFrame

**Параметри**:
- FFT Size: 256 (128 частотних барів)
- Bar Width: динамічно розрахований
- Gradient: від фіолетового до помаранчевого
- Frame Rate: ~60 FPS

**Код візуалізації**:
```typescript
const barHeight = (dataArray[i] / 255) * canvas.height * 0.8;
const gradient = ctx.createLinearGradient(0, y, 0, canvas.height);
gradient.addColorStop(0, '#8b5cf6');   // purple
gradient.addColorStop(0.5, '#ec4899'); // pink
gradient.addColorStop(1, '#f97316');   // orange
```

### 6.2 Адаптивний дизайн

**Mobile-first підхід**:
- Базові стилі для мобільних
- Поступове збільшення для більших екранів
- Використання Tailwind breakpoints

**Приклад**:
```tsx
className="text-xl sm:text-2xl md:text-3xl"
// Mobile: 1.25rem
// Tablet: 1.5rem
// Desktop: 1.875rem
```

### 6.3 Performance оптимізації

1. **Lazy loading** для відео (тільки в модальному вікні)
2. **Мемоізація** компонентів (можна додати React.memo)
3. **Одноразове створення** AudioContext
4. **Cleanup** в useEffect для запобігання витоків пам'яті
5. **Оптимізовані зображення** (Unsplash CDN)
